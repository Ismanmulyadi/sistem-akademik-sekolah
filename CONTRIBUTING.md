# Panduan Kontribusi

Terima kasih sudah tertarik berkontribusi ke proyek Sistem Akademik Sekolah! Ikuti panduan berikut sebelum mulai.

## 1. Alur Branch

Selalu buat branch baru dari `main` untuk setiap perubahan. Gunakan format:

- `feature/nama-fitur` — untuk fitur baru
- `fix/nama-bug` — untuk perbaikan bug
- `docs/nama-dokumen` — untuk dokumentasi

## 2. Format Commit Message

Tulis pesan commit yang jelas dan deskriptif, contoh:

- ✅ "Tambah validasi form login"
- ❌ "update"

## 3. Sebelum Membuat Pull Request

Pastikan sudah memeriksa:

- [ ] Kode sudah diuji secara lokal dan berjalan tanpa error
- [ ] Deskripsi PR jelas (apa yang berubah dan kenapa)
- [ ] Tautkan ke Issue terkait (jika ada)

## 4. Melaporkan Bug atau Usulan Fitur

Gunakan fitur **Issues** di GitHub untuk melaporkan bug atau mengusulkan fitur/ide baru, sebelum mulai membuat perubahan kode.
