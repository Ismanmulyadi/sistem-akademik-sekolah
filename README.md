# sistem-akademik-sekolah

Sistem informasi akademik sekolah - modul nilai siswa dan absensi

## Fitur (dalam pengembangan)

- Manajemen data siswa
- Input dan rekap nilai
- Pencatatan absensi harian

## Status Proyek

Dalam tahap pembelajaran — proyek ini dikembangkan bertahap
mengikuti roadmap belajar Software Engineer.

## Teknologi yang digunakan

- Backend: Node.js, Express
- Database: MySQL/MariaDB
