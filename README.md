# Sistem Akademik Sekolah

Sistem Akademik Sekolah adalah aplikasi untuk mengelola data nilai ujian
dan absensi siswa yang digunakan oleh guru mata pelajaran dan staf tata usaha.

## Fitur

### Guru

- Input nilai siswa per mata pelajaran
- Input absensi siswa (hadir/izin/sakit/alfa)
- Cetak rapor (khusus wali kelas)

### Siswa

- Lihat nilai ujian
- Lihat riwayat absensi

## Teknologi yang digunakan

- Backend: Node.js, Express
- Database: MySQL/MariaDB
